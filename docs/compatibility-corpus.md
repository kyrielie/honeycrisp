# EPUB compatibility corpus

The parser and reader tests create small EPUB structures in temporary
directories. They cover EPUB2 NCX navigation, EPUB3 manifest-declared navigation,
nested TOC entries, fragments, missing TOCs, missing metadata, non-linear spine
items, search offsets, and DRM detection. They are generated by
`EPUBParserTests` and `TOCParserTests`; run them with `./test.sh`.

## Synthetic fixture expectations

| Fixture | Expected behavior | Reproduction |
|---|---|---|
| EPUB2 package with NCX | Spine follows OPF order; NCX hierarchy and fragments are preserved | `testParsePackageFollowsContainerAndSpineOrder`, `testNCXParserPreservesHierarchyAndReadingOrder` |
| EPUB3 package with declared `nav` item | Manifest `nav` wins over filename guessing; nested TOC and landmarks are retained | `testManifestNavigationLandmarksAndNonLinearSpineAreRetained`, `testEPUB3NavigationPreservesNestedHierarchyAndManifestFragments` |
| Missing navigation document | Spine filenames provide a usable TOC | `testMissingTOCUsesSpineFilenamesAsFallback` |
| Empty metadata and non-linear front matter | Title falls back to the file name in the reader; Start Reading uses conservative front-matter rules | `testManifestNavigationLandmarksAndNonLinearSpineAreRetained`, `testStartReadingUsesBodymatterLandmarkThenConservativeFrontMatterFallback` |
| DRM marker | The parser reports a specific protected-book error | `testDRMErrorTakesPrecedenceOverMissingContainer` |
| Search text with HTML entities and supplementary Unicode | Search results retain a UTF-16 offset and a readable excerpt | `testSearchResultsRetainChapterAndUTF16TextOffsets` |

## Real-file validation

The workspace has a local `samples/` directory, but its files do not have a
source and redistribution manifest. Do not add those files to Git or copy their
contents into test resources. `.gitignore` excludes the local corpus. Before a
real-file validation run, record the source and redistribution terms for each
fixture here, then exercise Open, TOC, internal links, scroll, paginated reading,
search, and resume on-device. Keep the EPUBs on the local machine.

behavior are verified for each real sample. No personal book files belong in
this repository.
