Honeycrisp

A native EPUB reader for macOS

Download Install with Homebrew

Free and open source. Requires macOS 13 or later. Releases are not notarized, so see first launch.

quiet, native, and out of the way

Just for macOS

Built with AppKit and WebKit. Multiple windows or tabs, one book each, and light or dark appearance that follows the system.

Two reading modes

Paginated pages with configurable columns per screen, or one continuous scroll with auto-scroll. Pick the default in Settings.

Open source

MIT licensed. Report bugs and request features on the issue tracker.

Install

Homebrew

brew install --cask kyrielie/yggdrasil/honeycrisp

Manual download

Get the latest build from Releases and move it to Applications.

First launch

Releases are ad-hoc signed and not notarized, so Gatekeeper blocks the first launch. Open System Settings > Privacy & Security and choose Open Anyway, or run:

xattr -d com.apple.quarantine /Applications/Honeycrisp.app

Features

Themes

Save your preferred typography and colors as a named theme.

Text to speech

Read aloud from the current reading position.

Search in book

Results with excerpts and chapter locations.

Table of contents

A sidebar and a popup. Start Reading follows EPUB landmarks when the book provides them.

Bookmarks

Toggle one per page, rename it, and return from the Bookmarks menu.

Reading history

File > Open Recent and a History popover remember your place.

Float on top

Pin any window above all others.

Drag and drop

Drop an EPUB onto an empty reader window or an open book.

Custom shortcuts

Rebind the main commands in Settings > Shortcuts.

Customizable toolbar

Choose what it shows, including the title and the page counter.

What it does not do

Honeycrisp reads one book per window. There is no library view and no cross-library search. For library management see ambrosia; for iOS see nectar.
